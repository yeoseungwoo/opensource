# 셸 프로그래밍 실습 (Ex.3 셸 스크립트 활용)

- 학번: 20261707
- 이름: 여승우

## 폴더 구조
```
.
├── doc/   보고서 (셸프로그래밍(20261707,여승우).docx)
└── src/   소스 파일 (ex3-0.sh ~ ex3-9.sh)
```

## 실행 방법
```bash
cd src
chmod +x *.sh
./ex3-1.sh 17 5
```

| 파일 | 내용 |
|---|---|
| ex3-0.sh | MYENV 환경변수 .bashrc 등록 / 유지 확인 / 해제 (`set`, `check`, `unset`) |
| ex3-1.sh | 두 정수 인자 사칙연산 |
| ex3-2.sh | y = ½x² 계산 (실수, 2개 이상 입력) |
| ex3-3.sh | 점수 → A/B 등급, 평균 등급 |
| ex3-4.sh | 성적 관리 메뉴 (추가/보기/평균/GPA/종료) |
| ex3-5.sh | 시스템 상태 메뉴 + 내부 함수에 옵션 전달 (`./ex3-5.sh -h`, `./ex3-5.sh -l`) |
| ex3-6.sh | 폴더 확인·생성, 파일 5개 생성, 압축 및 새 폴더에 해제 |
| ex3-7.sh | 파일 이름별 하위 폴더 생성 + 심볼릭 링크 |
| ex3-8.sh | 팀원 정보 DB.txt 기록 (`-n` 옵션: 새로 작성) |
| ex3-9.sh | DB.txt 이름 검색 |
